# Tokyo Subway Journey Planner

Unofficial trip planner for the Tokyo subway: all 9 Tokyo Metro lines and the 4 Toei lines.
It's the Tokyo counterpart of the Namma Metro planner, in the same single-file format.

Enter where you're starting (GPS, an address, a landmark or a station) and pick a destination
station (English, Japanese or a code like `G09`). The planner:

- Tries the nearest few stations and picks the quickest once walking time is counted
- Gives the line and direction for every train, as station signs show it
  ("Ginza Line, trains for Asakusa"), with the station code
- Explains each change, including connected stations with different names
  (Akasaka-mitsuke ⇄ Nagatacho, Ginza ⇄ Ginza-itchome, Kasuga ⇄ Korakuen, …) and
  the Tokyo Metro ⇄ Toei transfer gates
- Handles the Oedo Line's loop: trains from the Shinjuku side terminate at Tochomae
- Shows total time, arrival time (Tokyo time), and the IC card and ticket fares, with
  the ¥70 Metro ⇄ Toei connecting discount
- Warns when it's late at night and the trains have stopped

## Run

It's a static page. Serve the folder and open `TokyoSubwayPlanner.html`:

```bash
python3 -m http.server 4610
```

GPS only works on `localhost` or HTTPS.

## Address search

Without a key, place search uses OpenStreetMap (Nominatim). For Google Places results,
copy `config.example.js` to `config.js` and add a Maps Platform key with Places API (New)
and Maps JavaScript API enabled. `config.js` is gitignored.

## Deployment

Hosted on Netlify. `netlify.toml` publishes the planner as `index.html` and writes
`config.js` from the `GOOGLE_MAPS_API_KEY` environment variable when it's set
(Site configuration → Environment variables); without it the live site uses OpenStreetMap search.

```bash
npx netlify-cli deploy --build --prod
```

## Station data

The `METRO` data block in the HTML is generated by `tools/build_stations.py`. It downloads
the Tokyo Metro and Toei route relations from OpenStreetMap, merges each line's stop into
one station, assigns station codes and scales distances to each line's official length.

```bash
python3 tools/build_stations.py
```

Fares and the timing model live at the top of the script in the HTML. Fares and times are
estimates; always follow in-station signage and the official fare charts.
